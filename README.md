Projekt inteligetný kvetináč
Vytvorili Patrik Dančo a Samuel Pochyba 
Softvér - Patrik Dančo  
Hardvér - Samuel Pochyba
Tento projekt predstavuje inteligentný systém na polievanie rastlín založený na mikrokontroléri ESP32. Sleduje vlhkosť pôdy, svietivosť slnka a teplotu a automaticky zabezpečuje polievanie,
prípadne umožňuje manuálne ovládanie cez webové rozhranie.

Systém momentálne podporuje 10 profilov rastlín (napr. kaktus, bazalka) a obsahuje aj vlastný režim, kde si používateľ môže nastaviť dĺžku polievania a čas (konkrétnu hodinu).
